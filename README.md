# The Solvability Dichotomy for Commutator-Tree Mixing in Finite Groups

Ernest Darell Zermeño — Universidad Panamericana, Campus Guadalajara.

This repository contains the article, an extended version, the LaTeX sources
of both, and the standalone verification artifact.

Label the leaves of a balanced commutator tree by elements of a
conjugation-closed generating set of a finite group, and read every
occurrence of the expanded word independently, as its element or the
identity. The paper determines when every valid tree gives a random walk
with a spectral gap in every non-trivial irreducible representation.

- **Dichotomy.** For a non-solvable group this happens from some depth on
  exactly when every proper subgroup generated by leaf elements is solvable,
  and the first such depth is the largest derived length of those subgroups.
- **Minimal simple groups.** A finite non-abelian simple group is minimal
  simple exactly when every non-trivial conjugacy class has such a depth; it
  is then at most 5, attained by the involutions of PSL(3,3).
- **Octahedral pairs.** For primes q ≡ ±3 (mod 8), q ≠ 3, every pair of
  exterior S4 subgroups of PGL(2,q) meeting in an S3 is conjugate to a pair
  defined by Hamilton's quaternions, and the largest cosine between their
  fixed spaces is at most √3/2, with asymptotic equality. The constant is the
  Ramanujan bound of the Lubotzky–Phillips–Sarnak graph X^{3,q}.
- **Rank one and rates.** Involution classes of PGL(2,q) and PSL(2,q) are
  classified, and fixed-error mixing holds in the optimal depth
  Θ(log log |G|) in the unobstructed families.

The companion paper "Uniform Mixing in Barrington Branching Programs" was
published in IACR Communications in Cryptology, Volume 3, Issue 3,
October 2026 (DOI [10.62056/a69qdkmol](https://doi.org/10.62056/a69qdkmol)).

## Article and extended version

The article is the version intended for journal publication. The extended
version has the same main results and additionally contains:

- localisation of obstructions under quotients (perfect cores, Frattini
  kernels, product quotients);
- averaging leaves and the decidability of the criterion;
- rigid templates: persistence of validity and the levels realised by
  prescribed families of configurations;
- the computational section with its tables, and a list of open problems.

The artifact is unchanged from version 1.0 and serves both versions. Its
scripts `bridge_*`, `target_transition_graph.py`,
`binary_target_grammar_certificate.py` and `test_bridge_sweeps.py` concern
rigid templates, and the reduced sweeps `generates_G.py`,
`geometric_lemma.py`, `derived_length_test.py`, `gl3f2.py`, `gl2z4.py`,
`mixing_level_pgl.py`, `bottleneck_pgl7.py` and `noninvolution_leaves.py`
produce the tables of the computational section. These are cited only in the
extended version. Where the artifact README says "the manuscript", statements
about those scripts refer to the extended version.

## Compile

With a LaTeX installation providing `pdflatex` and `bibtex`:

```bash
cd paper            # or paper-extended
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Run the verification artifact

Python 3.9+, NumPy 1.24+ and SymPy 1.12+ are required.

```bash
cd artifact
pip install -r requirements.txt
python3 scripts/run_validation.py --output validation-output --jobs 2
```

The runner records every command, exit status, duration and log hash.
Individual scripts can be run from `artifact/scripts/`.
